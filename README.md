# Plurai concept · unofficial

A one-screen design concept by Gaurav Basantani (https://gauravbasantani.com): a Plurai simulation report where a proposed fix would teach a made-up airline's support agent an out-of-date rule, and a source check asks the engineer to look at the passage before accepting.

- Live page: https://gauravbasantani.github.io/plurai-concept/
- Walkthrough (42 seconds): https://gauravbasantani.github.io/plurai-concept/walkthrough.mp4

The airline, people, agent and Run are made up. Report labels follow Plurai's public docs (docs.plurai.ai). Not affiliated with Plurai.
